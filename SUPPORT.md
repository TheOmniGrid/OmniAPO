# Support

This repository is the public documentation and support home for OmniAPO. It does not host application binaries, private source code, signing material, or private download links.

## Before opening a request

1. Check [README.md](README.md) and [FAQ.md](FAQ.md) when available.
2. Confirm the product version and the exact Windows, browser, or client version involved.
3. Reproduce the problem once with the smallest safe set of steps.
4. Remove usernames, local paths, account identifiers, license data, and other personal information from screenshots or logs.

## Public support

Use [GitHub Issues](https://github.com/TheOmniGrid/OmniAPO/issues) for reproducible product problems and documentation corrections. Include:

- product version and platform;
- expected and actual behavior;
- minimal reproduction steps;
- privacy-redacted screenshots or logs when useful.

## Private reports

Send suspected vulnerabilities to [omnivex@theomnigrid.biz](mailto:omnivex@theomnigrid.biz) instead of opening a public issue. Distribution questions that require account or delivery details also belong in email.

Support is best-effort. Do not publish private download links, installers, runtime payloads, credentials, or unredacted diagnostics.
