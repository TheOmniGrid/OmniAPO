# Contributing

OmniAPO is a public product and documentation repository. The application source tree, installers, binaries, signing material, and private build infrastructure are intentionally outside this repository.

## Contributions that fit this repository

- corrections to public documentation;
- broken-link and navigation fixes;
- privacy-safe screenshot or accessibility improvements;
- reproducible issue reports;
- clarifications to compatibility, installation, safety, or support guidance.

Do not submit application binaries, third-party payloads, private source material, credentials, personal data, or unofficial download links.

## Workflow

1. Open an issue for substantial changes so scope and evidence are clear.
2. Keep each pull request focused on one documentation concern.
3. Preserve existing product facts, legal boundaries, and OmniVex terminology.
4. Check every relative link and remove personal information from examples.
5. Describe what changed and how it was verified.

By contributing, you confirm that you have the right to submit the material and allow it to be published under the terms that apply to this repository.
